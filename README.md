# TooBarter — площадка обмена машин и недвижимости

Готовый рабочий сайт: люди выкладывают автомобиль или недвижимость, получают предложения обмена (с доплатой в любую сторону) и договариваются в личном чате, который открывается только после принятия предложения.

Интерфейс на трёх языках: **армянский, русский, английский** — переключается в шапке, выбор запоминается.

---

## Запуск

```bash
npm install          # зависимости
npm run seed         # демо-данные (можно пропустить)
npm start            # http://localhost:3000
```

Демо-аккаунты после `npm run seed` (пароль у всех `demo1234`):
`ani@demo.am` · `davit@demo.am` · `mher@demo.am` · `lilit@demo.am`

Другие команды:

```bash
npm run reset        # удалить базу и загруженные фото
npm test             # автотест интерфейса (нужен npm install с devDependencies)
```

`npm test` рассчитан на свежие демо-данные: перед прогоном сделай `npm run reset && npm run seed`, запусти сервер и только потом тест.

Порт и секрет JWT можно задать через переменные окружения (`PORT`, `JWT_SECRET`), см. `.env.example`. Если секрет не задан, он генерируется один раз в `data/.jwt-secret`.

## Что умеет

**Аккаунт.** Регистрация и вход по почте и паролю (bcrypt + JWT на 30 дней), профиль с именем, телефоном, городом и языком, смена пароля.

**Объявление.** Две категории:

- **Автомобиль** — марка (список из ~40 марок с подсказками моделей), модель, год, пробег, кузов, коробка, топливо, объём двигателя, привод, цвет, руль.
- **Недвижимость** — участок, дом, квартира, коммерческая: площадь, площадь участка, комнаты, этаж, этажность, состояние, адрес.

Плюс общее: заголовок (соберётся сам, если не заполнить), описание, город, оценочная стоимость с валютой (USD / AMD / EUR / RUB) и до 12 фотографий с перетаскиванием, удалением и выбором главной.

**Доплата.** У объявления и у каждого предложения указывается направление: без доплаты, `+` в мою сторону, `−` с меня, плюс сумма и валюта. В интерфейсе `+` всегда зелёный, `−` оранжевый.

**Условия обмена.** Главное отличие от обычной доски объявлений: владелец описывает не «хочу квартиру», а конкретные условия. Вариантов может быть до восьми, они соединяются по «или»:

> 01 · Автомобиль — Mercedes-Benz A-Class, 2020+, пробег до 80 000 км, доплата мне от $5 000
> 02 · Земельный участок — Дилижан, от 6 соток
> 03 · Квартира — Ереван, от 60 м², от 2 комнат

Конструктор динамический: меняешь категорию — набор полей перестраивается (для машины марка/модель/год/пробег/коробка/топливо/кузов, для недвижимости город/площадь/участок/комнаты), у каждого варианта своя доплата («мне минимум N» или «я доплачу не больше N») и свой комментарий. Условия видны на странице объявления карточками, а в ленте — короткой строкой в полосе `⇄`.

**Предложения — только своим объектом.** Предложить обмен «на словах» нельзя: объект нужно иметь в профиле, он и добавляется к сделке. Если объявлений нет, вместо формы появляется приглашение сначала выложить своё.

Пока заполняешь предложение, соответствие условиям проверяется вживую: под выбором объекта построчно видно, что подходит, а что нет («✓ Марка: Mercedes-Benz», «✕ Год: нужен ≥ 2020, у тебя 2014»). Если не хватает только доплаты — рядом кнопка, которая подставляет требуемый минимум. Отправить не подходящее под условия предложение можно, но кнопка честно меняется на «Всё равно отправить», а владелец увидит на нём пометку «Вне условий».

Владельцу запрос приходит во «Входящие» со счётчиком в шапке; он **принимает** или **отклоняет**. Отправитель может забрать предложение назад.

**Сохранённые поиски и оповещения.** Можно описать, что ищешь — «Toyota от 2016 дешевле $25 000» или «квартира в Ереване от 60 м², от 2 комнат» — и получать сигнал, как только появится подходящее объявление. Поиск создаётся двумя способами: кнопкой 🔔 прямо в ленте (текущие фильтры переносятся в него автоматически) или вручную на странице «Поиски».

Когда кто-то публикует объявление, сервер сверяет его со всеми активными поисками тем же модулем, что проверяет условия обмена. Совпало — владельцу поиска прилетает уведомление, он открывает объявление и сразу отправляет своё предложение.

Оповещения приходят тремя способами: счётчиком в шапке и полосой в начале ленты, всплывающим сообщением, если приложение открыто, и push-уведомлением на телефон, когда приложение закрыто (Web Push с VAPID; ключи сервер генерирует сам при первом запуске в `data/vapid.json`). Каждый поиск можно поставить на паузу или удалить, а страница «Поиски» показывает, сколько объявлений подходит под него прямо сейчас.

**Подбор.** В ленте есть фильтр «⇄ Что подойдёт моему объекту»: выбираешь свою машину или квартиру и видишь только те объявления, под чьи условия она проходит. На странице чужого объявления подсказка сразу называет, какие именно твои объекты подходят.

**Чат.** Создаётся сервером только в момент принятия предложения — до этого написать нельзя, эндпоинты чата отдают 404 всем, кроме двух участников сделки. Внутри — история, счётчик непрочитанных, автообновление раз в 3 секунды.

**Ещё.** Поиск по тексту, фильтры (категория, тип недвижимости, марка, год, город, направление доплаты, диапазон цены), 5 сортировок, пагинация, избранное, статусы объявления (активно / скрыто / обменяно), счётчик просмотров.

**Отзывы.** После принятого предложения обе стороны могут один раз оценить друг друга (1–5 звёзд + комментарий) — из чата или из списка предложений. Средний рейтинг и число отзывов видны на странице объявления рядом с владельцем и открываются списком по клику.

**Жалобы.** Кнопка «Пожаловаться» на странице объявления отправляет жалобу (спам, обман, неверная категория и т.д.) в очередь на модерацию в админке, откуда можно сразу скрыть объявление или заблокировать пользователя.

**Реферальная программа.** У каждого пользователя есть персональная ссылка (профиль → «Пригласи друга»). Регистрации по ней недостаточно: бонусные дни бесплатного поднятия в топ начисляются приглашённому и пригласившему только после того, как новый пользователь опубликует первое объявление. Бонус тратится вместо квитанции прямо в окне поднятия объявления.

**Тарифы для дилеров.** Бесплатно можно держать активными до `FREE_LISTING_LIMIT` объявлений одновременно (по умолчанию 3); тарифы «Старт / Про / Безлимит» (`/#/packages`) поднимают этот лимит на 30 дней — заявка подтверждается вручную в админке, как и поднятие в топ.

**Напоминания.** На странице «Мои объявления» залежавшиеся объявления (без фото или давно не обновлявшиеся — `STALE_LISTING_DAYS` дней) получают подсказку обновить фото или поднять в топ.

**SEO и превью для соцсетей.** У каждого объявления есть отдельный статический адрес `/l/:id` (в отличие от внутреннего `#/l/:id` на хеше, который поисковики не видят) с серверным рендером заголовка, описания, изображения и Open Graph/Twitter-тегов — по нему строятся `sitemap.xml`, `robots.txt` и ссылка кнопки «Поделиться».

## Мобильное приложение

Сайт установлен как приложение: на Android — кнопка «Установить» в баннере и в профиле, на iPhone — «Поделиться» → «На экран „Домой“». После установки открывается со своей иконкой, без адресной строки, на весь экран, с нижней панелью вкладок.

Что для этого есть в проекте:

- `public/manifest.webmanifest` — имя, цвета, иконки и быстрые действия по долгому нажатию на иконку (разместить объявление, предложения, сообщения);
- `public/sw.js` — service worker: оболочка и фотографии сохраняются, поэтому приложение открывается без сети; данные (`/api/…`) всегда берутся свежими, а без интернета показывается понятная заглушка;
- push-уведомления: `web-push` на сервере плюс обработчики `push` и `notificationclick` в `public/sw.js`. Работают на Android и на iOS 16.4+, но только для установленного приложения и только по HTTPS;
- `public/icons/` — иконки 192/512, maskable для Android и apple-touch-icon для iOS. Нарисованы скриптом, перерисовать можно командой `npm run icons`.

### Как открыть его на телефоне

**1. Проверить на компьютере.** `npm start`, открыть `http://localhost:3000` в Chrome — в адресной строке появится значок установки. Внутри всё работает как на телефоне: DevTools → значок телефона (Ctrl/Cmd+Shift+M) покажет мобильную вёрстку с нижними вкладками, вкладка Application → Manifest и Service Workers — что приложение собрано правильно.

**2. Открыть на своём телефоне.** При запуске сервер печатает адрес вида `http://192.168.х.х:3000` — набери его в браузере телефона, подключённого к тому же Wi-Fi. Сайт откроется полностью, но кнопки «Установить» не будет: браузеры разрешают установку и офлайн-режим только на HTTPS.

**3. Получить HTTPS за одну команду.** В соседнем терминале, не останавливая сервер:

```bash
npx localtunnel --port 3000        # выдаст адрес вида https://xxxx.loca.lt
```

Открой этот адрес на телефоне — появится предложение установить приложение. Localtunnel при первом заходе просит ввести твой внешний IP (он показан на самой странице). Альтернатива без этого шага — `cloudflared tunnel --url http://localhost:3000`, но cloudflared надо поставить отдельно.

**4. Боевой вариант.** Выложить на сервер с доменом и сертификатом — тогда приложение ставится у всех и навсегда. Самый короткий путь — Caddy, он сам получает сертификат Let's Encrypt:

```
твой-домен.am {
    reverse_proxy localhost:3000
}
```

**App Store и Google Play.** Этот репозиторий содержит только веб-версию. Нативные обёртки — отдельные проекты рядом с этим:

- [`toobarter-android`](../toobarter-android) — Capacitor-проект для Google Play
- [`toobarter-ios`](../toobarter-ios) — Capacitor-проект для App Store

Оба открывают адрес сайта из `server.url` в своём `capacitor.config.json` (сейчас `https://toobarter.onrender.com`, поменять на боевой домен, когда он привяжется — см. `render.yaml`); код и логика самого приложения остаются только здесь. Инструкции по сборке и публикации — в README каждого из них.

Отдельный нативный код на React Native имеет смысл, только если понадобятся вещи, которых нет в вебе: пуш-уведомления с фоновой доставкой, работа с камерой в обход браузера, глубокая офлайн-синхронизация.

## Как устроено

```
server.js          Express-API: авторизация, объявления, условия обмена, предложения, чат
db.js              схема SQLite (создаётся при первом запуске)
seed.js            демо-данные и генерация изображений-заглушек
public/
  index.html
  css/app.css      стили
  js/i18n.js       словари hy / ru / en
  js/catalog.js    города, марки и модели, справочники
  js/api.js        обёртка над fetch
  js/match.js      проверка условий обмена (общий файл для сервера и браузера)
  manifest.webmanifest, sw.js, icons/   установка на телефон и офлайн-режим
  js/ui.js         форматирование, тосты, модалки
  js/app.js        роутер и все страницы
tools/fronttest.js автотест интерфейса в jsdom
tools/icons.js     генератор иконок приложения
data/              база SQLite (в git не попадает)
uploads/           загруженные фотографии
```

Стек намеренно простой: Node + Express + SQLite (better-sqlite3) и фронтенд без фреймворка — проект запускается одной командой и не требует внешней базы.

### API

| Метод | Путь | Назначение |
|---|---|---|

## Если выкладывать в интернет

Проект рабочий, но перед публичным запуском стоит добавить: HTTPS и обратный прокси (nginx), ограничение частоты запросов на вход и регистрацию, подтверждение почты и телефона, сжатие загружаемых фото (например, через `sharp`) и резервное копирование `data/` и `uploads/`. Очередь жалоб для ручной модерации уже есть (админка → «Жалобы»), но автоматической проверки контента при публикации нет.
